How the connection works

Our open protocol establishes a secure remote connection between your wallet and dApps through an encrypted bridge server.

01
Your Wallet
Initiates connection request
02
Bridge Server
Relays encrypted messages
03
dApp Connected
Secure session established
ENCRYPTION
End-to-End Encrypted

All messages between wallet and dApp are encrypted using asymmetric cryptography. The bridge server cannot read your data.

AUTH
Mutual Authentication

Both wallet and dApp verify each other's identity before establishing a session. No man-in-the-middle attacks possible.

PERFORMANCE
Sub-Second Latency

Optimized bridge infrastructure across 35+ regions ensures near-instant message delivery and transaction signing.
